# Wave-Based Shooter Project

A-Level Computer Science programming project developed in 2024. It achieved a final mark of **57/60** (solid A* standard).

## Overview

This is a tactical wave-based shooter game built to demonstrate advanced programming concepts, clean architecture, and responsive gameplay mechanics. Players must survive escalating waves of enemies by balancing offensive combat strategies with resource and health management.

## Game Levels

*   **Level 1: Fundamentals**
    *   Introduces core combat mechanics, shooting controls, and healing systems.
    *   Designed to ease the player into the game's pacing and rhythm.
*   **Level 2: Close Quarters**
    *   Increases enemy density within an enclosed, restricted environment.
    *   Demands tighter reaction times, crowd control, and spatial awareness.
*   **Level 3: The Arena & Boss Finale**
    *   Takes place in a massive open area populated by large groups of hostile units.
    *   Introduces a specialized encounter that forces target prioritization.
    *   Concludes with a boss fight finale testing all accumulated skills.
